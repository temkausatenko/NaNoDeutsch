Komparation der Adjektive

ступені порівняння прикметників

🚨 ТРИ СТУПЕНІ:
  • Positiv — базова форма: schnell. Рівність: so … wie.
  • Komparativ — основа + -er (± умлаут): schneller. Порівняння: … als.
  • Superlativ — am … -sten / der/die/das … -ste: am schnellsten · der schnellste.

1. Positiv (so ... wie)

Базова форма без змін, використовується для опису або вказівки на рівність.

  • so + Positiv + wie: Kaffee ist so lecker wie Tee. (Кава така ж смачна, як і чай).
  • nicht so + Positiv + wie: Mein Handy ist nicht so teuer wie deins. (Мій телефон не такий дорогий, як твій).
  • doppelt / dreimal so + Positiv + wie: Das Haus ist doppelt so groß wie meine Wohnung. (Будинок удвічі більший, ніж моя квартира).

2. Komparativ (... als)

Використовується для порівняння. Додаємо закінчення -er. Односкладові прикметники з a, o, u часто отримують умлаут: alt → älter, groß → größer, kalt → kälter.

Прикметники на -el / -er / -eu втрачають e: dunkel → dunkler, teuer → teurer.
  • Komparativ + als: Er ist älter als ich. (Він старший за мене).

3. Superlativ (am ...-sten)

Найвищий ступінь. Додаємо суфікс -st, а после приголосних -t, -d, -s, -ß, -z, -x, -sch — -est.

  • Після дієслова: am + … + -sten: Im Winter ist es am kältesten. (Взимку найхолодніше).
  • Перед іменником: der/die/das + … + -ste: Das ist der höchste Berg. (Це найвища гора).
  • eine der + Superlativ (одна з най-): Berlin ist eine der interessantesten Städte.

5. Динаміка та Підсилення

  • immer + Komparativ (все більш...): Es wird immer kälter. (Стає все холодніше).
  • Je + Komparativ …, desto / umso + Komparativ … (чим ..., тим ...): Je mehr du übst, desto besser sprichst du. (Чим більше ти тренуєшся, тим краще говориш).
  • Підсилення (набагато): viel / noch / deutlich + Komparativ (Не sehr!). Das ist viel besser.

6. Типові помилки

❌ größer wie ich → ✅ größer als ich (після Komparativ завжди als)
❌ mehr groß → ✅ größer (ступінь утворюється суфіксом)
❌ das am schnellsten Auto → ✅ das schnellste Auto (перед іменником без am)
❌ alter als ich → ✅ älter als ich (не забувай умлаут)
