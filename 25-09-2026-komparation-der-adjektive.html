Komparation der Adjektive

🚨 ТРИ СТУПЕНІ:
  • Positiv — базова форма: schnell. Рівність: so … wie.
  • Komparativ — основа + -er (± умлаут): schneller. Порівняння: … als.
  • Superlativ — am … -sten / der/die/das … -ste: am schnellsten · der schnellste.

1. Швидка схема

СтупіньФормулаВикористання
Positivбазова формапростий опис, рівність (so … wie)
Komparativоснова + -er (± Umlaut)порівняння двох об'єктів (als), динаміка (immer), залежність (je … desto)
Superlativam … -sten / der/die/das … -steвиділення найкращого з-поміж усіх

2. Positiv

Базова форма без змін: Der Kaffee ist heiß.

  • so + Positiv + wie: Kaffee ist so lecker wie Tee.
  • nicht so + Positiv + wie: Mein Handy ist nicht so teuer wie deins.
  • doppelt / dreimal so + Positiv + wie: Das Haus ist doppelt so groß wie meine Wohnung.

3. Komparativ

Додаємо -er. Односкладові з a, o, u отримують умлаут: alt → älter, groß → größer, warm → wärmer.

Прикметники на -el / -er / -eu втрачають e: dunkel → dunkler, teuer → teurer.
  • Komparativ + als: Er ist älter als ich.
  • immer + Komparativ: Es wird immer kälter.
  • Je + Komparativ …, desto / umso + Komparativ …: Je mehr du übst, desto besser sprichst du.
  • Абсолютний Komparativ: ein älterer Herr (літній).
  • Підсилення: viel / noch / deutlich + Komparativ (не sehr!)

4. Superlativ

Суфікс -st, а після -t, -d, -s, -ß, -z, -x, -sch — -est.

  • Після дієслова: am + … + -sten: Im Winter ist es am kältesten.
  • Перед іменником: der/die/das + … + -ste: Das ist der höchste Berg.
  • einer / eine / eines der + Superlativ: Berlin ist eine der interessantesten Städte.
  • aller- + Superlativ: das allerbeste Geschenk

5. Топ-4 типових помилок

❌ größer wie → ✅ größer als
❌ mehr groß → ✅ größer
❌ das am schnellsten Auto → ✅ das schnellste Auto
❌ alter als ich → ✅ älter als ich
